# 家合 · Jiaho：明快版品牌提案

## 命名

- 中文：**家合**（本轮选用）。
- 英文品牌名：**Jiaho**，建议读作「家·和」。这是围绕中文名称创造的品牌写法。
- 视觉字标：**jiaho**，统一小写。
- 品类说明：**家庭 AI 中心 / Home AI Hub**。
- 品牌主张：**让 AI，走进每个家。**

相对 DepDek 的命名方向，本轮希望英文更轻快、易于口头呼叫，并让字形与图形建立联系：h 的拱形呼应家门，o 的圆形呼应智慧内核。Jiaho 是品牌候选名；本提案不代表商标或域名可用性结论。

## 视觉调整

1. 使用上一轮已选的新图标，保留细门框、太极式弯道及顺时针 45° 的方向。v3 在门框左侧延长字干，形成小写 **h** 的轮廓，让「家门」与 Jiaho 字标相互呼应。v4 收短上挑字干、缩小圆心，改善图形留白与视觉居中。v5 向两侧展开门柱，让下半部门洞更接近正方形，同时保留短字干和开口。
2. 改为居中的竖向组合：**图标 → jiaho → 家合 → 家庭 AI 中心**。
3. 橙色更明亮，玉绿更清新，搭配奶油白和深森林绿文字。
4. 背景角落用极浅杏色和薄荷色的大块留白形状增加轻快感。
5. 中英文均采用清晰圆润的字形，以开放、亲近、可靠为目标。

| 用途 | 目标色 |
| --- | --- |
| 门框 / 主强调 | 明亮橘 `#FF8429` |
| 智慧核心 | 清新玉绿 `#00B88A` |
| 名称 / 正文 | 深森林绿 `#153D35` |
| 主背景 | 奶油白 `#FFF9EE` |
| 辅助底色 | 浅杏色与浅薄荷色 |

这些是后续矢量化的目标色；PNG 概念稿中的局部色值与笔画仍需在矢量定稿时统一。
