# 家合 · DepDek：家庭 AI 中心品牌提案

本轮是基于已选「家门 + 太极圆」方向的品牌精修。命名、视觉与应用示意供评审；未改动应用名称、启动程序、接口或 ISO。

## 名称与定位

- 中文名：**家合**，读作 jiā hé。
- 英文名：**DepDek**，建议读作 dep-dek，沿用项目已经积累的名称。
- 品类说明：**家庭 AI 中心 / Home AI Hub**。
- 品牌主张：**让 AI，走进每个家。**
- 英文传播短句：**AI, at home.**

「家」是产品服务的对象和数据归属；「合」是一家人的连接，也是原件、知识和 Agent 能力的协作。口语中与「家和」呼应，适合面向普通家庭的温暖、可靠表达。

面向家庭的核心承诺：把散落的资料、值得保留的记忆和需要处理的事务组织起来，让一家人可以通过自然交流获得帮助。资料管理、家庭知识和 Agent 服务共同支撑这一定位。品牌传播中的功能承诺应与实际交付能力一致。

名称为创意提案；本轮未进行商标注册可用性核验，也未修改公司的法定名称或代码中的标识符。

## 标志概念：合家之门

**门**：普通家庭进入 AI 的入口，也是个人空间的边界。敞开的底部表达易于进入，稳定的门庭结构表达可靠。

**圆**：门内的家庭智慧核心。两瓣共成一个圆，表达人与 AI、一家人之间的协作；不附加传统太极鱼眼，维持简洁识别。

**弯道**：保留顺时针旋转 45° 后的 S 形留白，从右上连接左下，表达交流、流动与协调。

中国气质来自门庭、圆融和留白的关系；现代感来自清晰轮廓与克制配色。

## 视觉规范目标

| 项目 | 方向 |
| --- | --- |
| 主色 | 暖橙 `#EA7839`，用于门框与品牌强调 |
| 辅色 | 深玉绿 `#237D6B`，用于智慧核心 |
| 文字 / 深底 | 墨色 `#252C29` |
| 浅色底 | 暖白 `#F6F3ED` |
| 门框 | 统一、较轻的线重，顶部柔和转角，底端圆收口 |
| 内核 | 清晰的圆形外轮廓，宽而平滑的 S 形留白 |
| 字标 | 中文稳重清晰，英文采用易读的现代无衬线；避免装饰性笔画 |
| 安全空间 | 四周至少留出一个内核圆半径的空白 |

以上色值与比例是后续矢量定稿的目标。生成 PNG 是视觉概念稿，局部色值、轮廓和各示例比例尚不等于精确的矢量母版。

## 应用建议

1. **启动界面**：使用独立标志与小号 DepDek 字标，保持大面积留白。启动状态另放低干扰位置。
2. **中文产品页面**：使用标志、家合、DepDek 和「家庭 AI 中心」的主组合；狭小位置只显示标志。
3. **国际页面**：使用标志与 DepDek；需要解释品类时补 Home AI Hub。
4. **单色与小尺寸**：后续矢量化时分别检查 24、32、64 px 下的识别，确保太极弯道不会闭合。
5. **交互语气**：亲切、清楚、主动说明结果。例如「资料找到了，还缺一张购买凭证。」让用户感到有人帮忙处理家里的事。
