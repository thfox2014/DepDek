# 悟空 · 相册与资料

2026-10-19，基于已有相册的场景式交互扩展。用户可见的“宝箱/宝盒”更名为“相册”，新增并列“资料”入口。一个悟空、同一个聊天工作区，右侧按意图出现对应内容，不新增文件管理仪表盘。

## 产品主张

**不让用户管理文件结构，让资料在需要时出现。**

相册负责回忆，资料负责生活中的依据与准备。文件夹、介质、索引、解析和 KV 都是底层能力，不成为用户的任务。聊天识别意图后给出三个选择；场景推荐不是文件操作授权。

## 三个关键场景

| 场景 | 怎么对悟空说 | 右侧交互 | 至多三个主要操作 |
| --- | --- | --- | --- |
| 找一份 | “洗碗机的滤网怎么清洗？找一下说明书。” | 一条答案与一处原文。显示来源、章节、高亮段落，可展开核对。 | 查看原文、收进常用、继续追问 |
| 理一摞 | “刚放进来的装修资料，帮我理一理。” | 五份示例归成三个主题，区分版本与完全相同副本。对比两版变化，而不是直接删除旧版。 | 应用/撤销方案、看看版本差异、先放这里 |
| 办一件事 | “周末去露营，把要用的资料准备好。” | 围绕事项呈现已备资料与缺项。选择携带内容，再预览引用清单。 | 预览/记下清单、调整内容、看看还缺什么 |

三个场景不是三套皮肤：分别表达“答案→依据”“文件→关系”“事项→资料与缺项”。保留稳定的聊天、四行滚动处理摘要和场景选择，右侧内容随任务改变。窄屏收为抽屉，可返回聊天。

## 原型交付与本机续批

- `npm run preview:documents`：默认打开资料；`npm run preview:treasure`：默认打开相册，均复用 1431 的独立预览服务器。
- `/?workspace=documents&scene=find`、`scene=organize`、`scene=prepare` 可直接查看三幕。默认演示原生同一套可用流程，附加 `concept=1` 保留首轮概念稿；顶部 Tweaks 可切换入口与空/失败状态。
- 场景卡载入明确标注的示例对话。聊天只推荐场景，`找资料：关键词` 可填入查找框；必须显式点击查找/保存/导出，不接大模型、不自动执行文件操作。
- 首轮概念素材在 `scripts/fixtures/documentExamples.ts`，可用流程的隔离服务在 `scripts/fixtures/nativeDocuments.ts`。示例资料、收藏与清单只留当前页内存；可下载含虚构资料的真实 tar.gz，但不会读写 Home。
- 原生 `NativeDocumentsPanel` 使用真实文件索引和新增的用户专用 Vault 能力：有界 UTF-8 原文检索、PDF 本机 Canvas 预览、常用标记、可撤销分组、行内容比较、事项清单持久化、核验原件后归档导出。完整限制见 `document-library.md`。
- 收藏、分组和清单写入私有 redb 人工记录，索引刷新不清除；原件不移动、不改名、不删除。清单保存与 tar.gz 导出是两个独立动作，均不等于外部共享。
- 原生不注入演示内容。按 `contract.md` §3 增加 6 个 Tauri commands，Rust 与 TS 同步实现；sidecar 未注册这些方法，不新增 Agent 文件权限、Webdesk/R1 接口、扫描或云端调用。
- 尚未实现 OCR、Office 正文解析、PDF 全文检索、语义问答或自动推断事项缺项。文件名分组与行内容差异不冒充模型理解；原文填入聊天是用户显式动作，至多 2,000 字，未自动发送。

### 可用流程

“找一份”先查关键词，再打开匹配原文，可收藏或把短原文填入聊天草稿；检索明确显示正文预算与未查项。“理一摞”最多一页 50 份，修改名称提示的分组后保存到 KV；可撤销上次关系，勾两份比较原文，重复只以同内容指纹认定。“办一件事”手选原件、手填缺项，先保存清单，再导出含完整原件与 manifest 的 tar.gz。跨页选择可移除过期引用；文件变化和并发冲突都返回错误，不静默重扫或替换。

## 后续扩展建议（不是额外接口授权）

以已有文件内容指纹和来源为事实底座，逐步增加文档内容块与关系，不把模型文字当作文件事实。

1. 文档：稳定 ID、内容指纹、原件引用、类型、入库/修改时间。
2. 内容块：章节/页码/偏移、原文、提取方法；摘要必须能回到对应内容块。
3. 关系：主题、事项、版本前后、完全相同副本；相似不等于重复，“较新”也不自动等于正确版本。
4. 标签：来源、置信状态、用户修正；自动建议与用户确认分开存储。
5. 资料包：事项说明、选中的不可变内容引用、缺项与核对时间；导出和分享独立确认。

本批已完成有界文本检索、人工关系、内容引用和资料包导出；页码级内容块、OCR/语义索引及自动事项理解仍需独立设计与验收。扫描范围、解析预算、审计和来源验证继续在原有信任边界内；后续新增跨方接口前继续先更新 `docs/contract.md`。
