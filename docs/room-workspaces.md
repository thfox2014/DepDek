2026-10-25：在正式 `DepDekAiOsShell` 中扩展现有布局。按用户续批反馈，入口拆分为悟空、应用、相册、视频、资料、家庭、娱乐，聊天始终居中，右侧面板按目的地和聊天意图变化。原视频深链接/初始场景仍直接打开独立的视频工作区。

## 应用和 Agent Store

悟空头像只负责聊天与盒内伙伴，徽标统计已保存且去重的 Agent ID。桌面展开左栏显示伙伴，窄屏在 Dock 上方弹出名单，选择后收起。切换伙伴保留独立会话、草稿与已有历史，不再打开应用商店；自定义和历史保存的角色也能看见。应用是独立的商店图标，默认打开 Agent Store，仍可查看“我的 Agent”。只启动悟空的旧启动策略保持，其他伙伴在用户首次发送时才创建运行会话。

首期商店提供六个随包内置角色：文档管家、回忆整理师、家庭管家、音乐搭子、观影伙伴、灵感伙伴。它们是受控的角色提示词及现有技能组，不包含可执行程序。界面列出所用模型和启用技能，点安装通过原有 `settings_set` 保存 `SavedAgent`，成功后数量才更新。同 ID 重复安装不覆盖旧配置，Provider 必须已存在且符合当前联网/本地模式。

这一期没有远程商店接口、外部包下载/运行、付费、签名包更新或自动升级。界面明确写“内置角色包”。未来远程商店需要独立的目录、包校验及版本契约，不能把不可信下载内容直接注册为 Vault 权限或运行程序。

## 家庭

安保、健康、家居三个场景，各自最多一份4000字符的手工记录。`family_info_state` 和 `family_info_put` 为原生用户界面专用 Tauri 命令，数据存入当前 Home 的私有 redb 表 `family_scene_notes_v1`。读写复用 Vault 的登录、user-only、根切换锁、私有目录保护和成功/失败审计；保存带 libraryId 与 expectedRevision，事务内检查版本，旧空间/旧修订不能覆盖。空字符串可清空该幕的记录；重建文件索引不清除这些记录。

记录是本机用户资料，不宣称独立加密。安保设备、健康设备及智能家居均未接入，界面显示未接入；手工记录不代表实时监测结果。记录不会自动进入 Agent 或云端上下文。“交给悟空”仅将当前选中记录放入草稿，仍需用户发送；界面不展示模型内部推理。没有新增 sidecar 工具、R1 / Webdesk API 或设备权限。

## 视频与娱乐

视频是独立菜单，沿用已有原片播放、取样标注和故事清单；娱乐目前提供音乐，不再使用混合的 视频/音乐 页签。音乐支持从已有索引查找 MP3/WAV/OGG/FLAC，查找不扫描 Home、不读音轨；空查询按四种扩展名各取最多100条，关键词查询最多检查500条索引元数据，最后最多展示100首并标明部分结果。

用户选一首后通过 Vault 读取，复核元数据 SHA、大小、音频 MIME 和实际解码字节数，最大64 MiB。播放器使用本机 Blob URL，不自动播放，隐藏/切换时停止，退出释放 URL。添加音乐复用原有本机副本导入，刷新可见。尚未连接音乐平台，也没有音频内容理解或流媒体能力。

生产前端构建与上述34项前端回归通过，补充检查了独立菜单顺序、应用默认商店、娱乐不包含视频、视频深链接/三幕保留。隔离预览复看悟空名单、应用商店、独立视频与音乐入口；本轮未重打原生 `.app`，前一节原生包记录属于拆分前版本。

### 主菜单分组续批

最新菜单在图2紧凑悟空栏基础上分成四项：智能体（保留应用内的 Agent Store 与我的 Agent）、资料（右侧面板切换相册/视频/资料）、数据（沿用家庭的安保/健康/家居记录）、娱乐（右侧面板切换音乐/影视）。悟空头像及 Agent 数量仍单独置于主菜单上方；点击头像时，伙伴名单以浮层出现，不再扩展侧栏或挤压中央聊天。原有相册、视频、资料的场景、数据读写能力和深链接保留。影视标签先提供诚实的未接入状态，并可跳转到“资料/视频”查看本机原片；未连接影视来源前不展示线上片库。
