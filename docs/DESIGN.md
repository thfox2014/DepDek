# Overview

用户于 2026-10-18 确认文件模块采用与家合向导一致的暖白、墨绿风格。以 `src/components/ai-os-wizard.css` 为色彩来源，不改变整个 DepDek 工作台的既有主题。本声明只覆盖文件模块，后续增加其它页面时增量维护。

Design Read：家庭文件管理工具；暖色、安静、可信的资料柜；局部 Redesign · Preserve。视觉变化 3、动效 2、信息密度 7、素材依赖 2、品牌一致性 10。使用稳定三栏而非大卡片，重点给真实路径与可验证的内容哈希。

定位：主要是数据操作页，非品牌宣传页；面向桌面近距离阅读。暖而克制；窄屏优先收起详情而不是压缩路径或缩小字号。布局先交付 v0 供用户确认，再完成正式索引接线。

# Colors

暖白 `#fbf8f0` 为画布；纸白 `#fffdf8` 为数据表与控件；墨绿 `#23463c` 为主文字与主要动作。浅绿 `#eaf0e8` 仅表示选中或当前范围；`#77867a` 为次要文字；细线 `#e2e4d9` 分隔结构。棕色 `#a66d36` 只用于焦点描边与待确认提示，不新增无意义的彩色分类。

# Typography

沿用原生中文字体，不加载外部字体。页面标题 28–32px，文件名 15–16px，正文 14–16px，元信息不小于 12px。路径与 SHA 使用等宽字体；完整路径在详情中换行，不能只靠 tooltip 获取。标题字重 600，列表正文 400。

# Layout

左侧 196–212px 分类栏，中间 minmax(0,1fr) 文件表，右侧 280–320px 文件详情。顶部只有标题、搜索与索引操作，不堆叠统计卡。长列表和详情独立滚动；窄屏分类变为横向导航，详情变为折叠区域。目录浏览与个人资料入口必须保留，不能随分类替换而丢失。索引快照时间、范围与真实空状态必须可见。

# Elevation & Depth

主结构使用 1px 细线和纸面层次；避免悬浮卡片、玻璃拟态、大范围阴影。唯一轻阴影用于右侧浮层/弹层，不用于每条文件记录。

# Shapes

控件圆角 10px，模块容器 18px，表格行不做独立卡片。图标复用现有 Phosphor 图标；不绘制新的品牌 logo 或引入 emoji。

# Components

- 分类：全部文件、照片、文档、视频、邮件、其他；计数来自 KV 汇总，未接线的布局稿显示破折号，不编造数量。
- 搜索：文件名、相对路径、SHA；范围与加载状态清楚，正式版需 debounce 和过期请求保护。
- 文件表：文件与相对路径、类型、大小、修改时间；选中行浅绿，保留键盘可达性。
- 详情：原始路径、当前路径、完整 SHA-256、分类和识别依据、大小/时间；哈希复制与同内容检索为正式版后续接线。
- 刷新：显式动作，只重建索引，不搬动/删除原件；扫描前说明范围，过程中防重复提交。
- v0 提供密度与详情开关作为预览调节，不写入业务设置。

# Do's and Don'ts

保留文件原件与 Vault 权限边界；清楚区分布局稿、真实空数据与真实查询结果。未接线按钮必须标记或禁用。不为原生 UI 改 Webdesk、不授予 Agent 任意磁盘权限。不自动触发真实 Home 扫描或模型调用。不伪造文件数、哈希、缩略图或分类准确率。

## 家合首个闭环 · 增量应用（2026-10-18）

依据用户确认的 Product Soul 和 less is more 要求，将相同暖白/墨绿系统用于独立首个闭环 v0，不改变运行中工作台。模式为 Redesign · Preserve：保留 Logo、悟空头像、语音草稿和设置可达性；收纳指标、模型选择与常驻空面板。

Design Read：家庭首次打开到再次使用的近距离桌面交互；暖而安静。视觉变化 2、动效 2、信息密度 3、素材依赖 3、品牌一致性 10。低密度意味着少默认控件，不降低隐私说明的可达性。只复用已有真实素材，不重新画角色。

叙事角色：输入与完成一件小事，不是宣传页；距离：桌面近距离，手机可回流；温度：温暖、克制；容量：首屏一条主句、一个输入框、两个起点，右侧默认没有内容。确认、原文、记忆和处理范围按任务出现。

颜色沿用上述具体值；正文 16px、输入 18px、欢迎语 `clamp(28px, 3.2vw, 40px)`。移动操作区域 44px，侧栏 208px，输入内容最大宽度 680px，右侧 320–360px。主结构细线、纸面层次，无渐变、无大卡片墙；120ms 状态反馈，减少动态效果时关闭头像动画。

独立稿的深色派生值：画布 `#18251f`、纸面 `#20322a`、文字 `#edf2e9`、次要文字 `#becabd`、分隔 `#3d5144`、选中 `#304c3e`；只供本稿主题切换，不覆盖原有深色系统。

v0 的示例、记忆与输入只留在当前页内存，不使用 localStorage；布局/字号/Tweaks 也是预览参数，不是业务设置。不在家庭页面常驻预览调节器；通过角落的小按钮打开，交付时可关闭。

## 首启网络与邮箱账户 · 局部扩展（2026-10-19）

模式为 Extension，不更换家合 Logo、四步结构或现有模型/模式页。面向家庭用户近距离桌面操作，沿用向导暖白、墨绿、细线及圆角；视觉变化 2、动效 2、信息密度 3、素材依赖 2、品牌一致性 10。只让“是否联网、下一步做什么”成为首屏重点，网卡/IP 信息折叠到网络详情，不添加指标墙。

网络状态使用文字与图标共同表达：绿色“已联网”，暖棕色“未联网/尚未确认联网”，旋转图标只用于正在检测；不能仅依赖颜色。状态变化通过 live region 宣告，保留重新检测、手动打开 Wi-Fi 与系统不支持时的说明。只自动打开一次设置，不随检测重复抢占用户焦点。

账户主入口为 BitBay 邮箱注册，不再把本机 admin 表单作为平台注册入口。真实平台注册使用邮箱、6 位验证码、12–20 字节密码及确认密码，提供已有账户登录分支；必须勾选数据发送目标说明后才启用发送/提交，倒计时防止连续发信。只在平台回执验证成功后显示“已关联”，不可把本机账户伪装成平台身份；本机空间创建/解锁保留为独立折叠的兼容路径。所有状态保持主按钮、焦点描边和原有表单校验。
