# Overview

用户于 2026-10-18 确认文件模块采用与家合向导一致的暖白、墨绿风格。以 `src/components/ai-os-wizard.css` 为色彩来源，不改变整个 DepDek 工作台的既有主题。本声明只覆盖文件模块，后续增加其它页面时增量维护。

Design Read：家庭文件管理工具；暖色、安静、可信的资料柜；局部 Redesign · Preserve。视觉变化 3、动效 2、信息密度 7、素材依赖 2、品牌一致性 10。使用稳定三栏而非大卡片，重点给真实路径与可验证的内容哈希。

定位：主要是数据操作页，非品牌宣传页；面向桌面近距离阅读。暖而克制；窄屏优先收起详情而不是压缩路径或缩小字号。布局先交付 v0 供用户确认，再完成正式索引接线。

# Colors

暖白 `#fbf8f0` 为画布；纸白 `#fffdf8` 为数据表与控件；墨绿 `#23463c` 为主文字与主要动作。浅绿 `#eaf0e8` 仅表示选中或当前范围；`#77867a` 为次要文字；细线 `#e2e4d9` 分隔结构。棕色 `#a66d36` 只用于焦点描边与待确认提示，不新增无意义的彩色分类。

# Typography

沿用原生中文字体，不加载外部字体。页面标题 28–32px，文件名 15–16px，正文 14–16px，元信息不小于 12px。路径与 SHA 使用等宽字体；完整路径在详情中换行，不能只靠 tooltip 获取。标题字重 600，列表正文 400。

# Layout

左侧 196–212px 分类栏，中间 minmax(0,1fr) 文件表，右侧 280–320px 文件详情。顶部只有标题、搜索与索引操作，不堆叠统计卡。长列表和详情独立滚动；窄屏分类变为横向导航，详情变为折叠区域。目录浏览与个人资料入口必须保留，不能随分类替换而丢失。索引快照时间、范围与真实空状态必须可见。

# Elevation & Depth

主结构使用 1px 细线和纸面层次；避免悬浮卡片、玻璃拟态、大范围阴影。唯一轻阴影用于右侧浮层/弹层，不用于每条文件记录。

# Shapes

控件圆角 10px，模块容器 18px，表格行不做独立卡片。图标复用现有 Phosphor 图标；不绘制新的品牌 logo 或引入 emoji。

# Components

- 分类：全部文件、照片、文档、视频、邮件、其他；计数来自 KV 汇总，未接线的布局稿显示破折号，不编造数量。
- 搜索：文件名、相对路径、SHA；范围与加载状态清楚，正式版需 debounce 和过期请求保护。
- 文件表：文件与相对路径、类型、大小、修改时间；选中行浅绿，保留键盘可达性。
- 详情：原始路径、当前路径、完整 SHA-256、分类和识别依据、大小/时间；哈希复制与同内容检索为正式版后续接线。
- 刷新：显式动作，只重建索引，不搬动/删除原件；扫描前说明范围，过程中防重复提交。
- v0 提供密度与详情开关作为预览调节，不写入业务设置。

# Do's and Don'ts

保留文件原件与 Vault 权限边界；清楚区分布局稿、真实空数据与真实查询结果。未接线按钮必须标记或禁用。不为原生 UI 改 Webdesk、不授予 Agent 任意磁盘权限。不自动触发真实 Home 扫描或模型调用。不伪造文件数、哈希、缩略图或分类准确率。

## 家庭感知中枢 · 独立概念原型（2026-10-22）

Extension，仅覆盖 `docs/design/jiaho-home-hub-v0/`。这是未来家庭硬件扩展的 v0，不替换运行中的悟空界面、产品 Soul 或正式接口。延续真实家合 Logo、现有 `WukongHead` 和上述暖白/墨绿/浅绿/暖棕色；不新增硬件产品渲染图、全家监控墙或新角色。

Design Read：家庭成员在桌面、家庭屏与手机上交谈、了解房间状态、核对记忆和控制已登记设备；温暖人文的安静工具。视觉变化 3、动效 2、信息密度 4、素材依赖 3、品牌一致性 10。稳定三栏为骨架，原型中的空间平面图只解释房间状态；动作后的回执、记忆依据和隐私状态承担重点。默认首屏不出现 CPU、Token、模型清单和完整传感器日志。

叙事角色是日常交互而非宣传页；阅读距离为桌面 50–80cm，家庭屏提供大字变体；视觉温度安静；容量限制为一个目标、一个当前上下文、一个主要动作。颜色与圆角沿用本声明，正文 16px、辅助信息 12px、主欢迎语 40–48px；侧栏 208px、聊天弹性宽度、右栏 340px。窄屏右栏为可关闭抽屉，触摸目标至少 44px。

五个设计表盘的直接后果：低变化保持现有左/中/右结构；低动效只用于状态反馈和悟空眨眼；中低密度将来源/设备细节延后展开；低素材依赖用真实品牌资产及语义图，不凭空画硬件；高品牌一致性复用已有深浅色派生值。原型提供标准三栏、大字陪伴、安静夜间三种显示变体，参数只留内存。

物理遮光罩状态常驻顶部，以文字和图标表达，不能被软件开关伪装。普通灯光控制直接给结果和撤销；新增自动化、扩大云端内容范围和高影响动作才在右侧核对。同意、推测、未知和已验证回执分别呈现。所有示例、按钮与模拟状态明确标为原型，不调用真实设备、摄像头、麦克风、模型或账户。

## 悟空家庭管家 · 连续对话原型（2026-10-22）

Redesign · Preserve，仅覆盖 `docs/design/jiaho-wukong-butler-v1/`；上一版保留。借鉴 Meta Muse 官方设计说明的连续主对话、后台任务、结构化产物和必要决定，而不是复制其品牌或把云端虚拟机模式套进本地 Home Server。产品设计梳理交互，前端设计落实为独立 HTML；正式 Shell、权限、接口与真实资料不变。

Design Read：家庭成员把日常事务交给一位可靠的管家；近距离桌面、家庭屏、手机。视觉为家合的暖白纸面与墨绿，变化 3、动效 3、密度 3、素材依赖 4、品牌一致性 10。叙事角色是持续陪伴和事务交接，不是欢迎海报或监控台；最多一个主要产物、一个必要决定。容量以中央对话优先，右栏默认收起，待确认或产物打开时才展示。左栏保留我的家、家的记忆、我的资料，并增加同一悟空的任务入口，不增加 Agent 角色。

沿用本文件全部颜色与系统中文字体。主标题 36–44px，正文 16px，辅助信息不低于 12px；左栏 216px、右栏 340–380px、聊天内容最大 720px，输入框始终可达。原始 Logo、悟空头像原样复用，图标来自仓库已安装的 Phosphor，不手绘新角色。120–220ms 控件反馈，头像只轻微呼吸，停止/减少动效可用；不会靠频繁随机表演索取注意。

聊天、语音草稿和后台任务可同时存在。用户不需要等一个任务结束才能继续输入；后台进展收成一条任务卡，不逐步刷屏。确认的是确有影响的选择，不是每次本机索引或读文件。取消是停止后续步骤，不宣称已执行的动作全部回滚；未知回执必须核实，不能自动重试。模型内部推理不展示，只显示已执行的可公开阶段。

三个内存变体为「日常管家」「陪伴大字」「专注办事」；深浅模式另设。示例语音不使用麦克风；示例整理不读取文件；下载清单也明确写“示例”。所有示例记忆只留当前页，忘记后不再召回；原型不输入真实凭据，不声称已经加密或连接设备。

## 独立手机端 `mobile/` · 实现（2026-10-22）

Extension：用户指定将上一版悟空管家做成独立手机前端。沿用家合资产、暖白/墨绿、纸面细线与对话语气，不改桌面、Webdesk 或三方协议。Design Read 为家庭用户单手交代事务、找回资料与核对必要选择；变化 3、动效 3、密度 3、素材依赖 4、品牌一致性 10。叙事角色是可随身打开的管家；阅读距离手机近距离；温暖但不制造依赖；单屏一项主动作。
