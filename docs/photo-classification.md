# 照片分类：牌堆、AI 标注与本机 KV

入口为相册「照片分类」。维度为人物（people）、事件（event）、景点（place）、内容（subject）。一张照片可以属于多个维度；分类是可纠正的内容索引，不移动/删除原件。

AI 使用收敛词表，避免“海滩/沙滩/海边”分裂成三组：people=单人/双人/多人合影/儿童入镜；event=生日/婚礼/毕业/聚餐/旅行/运动/演出/日常；place=海边/山野/公园/城市建筑/室内/乡村/展馆；subject=人像/风景/宠物/美食/花草/截图/票据/文档/物品/其他。必须提供画面依据，拿不准降低 confidence 或留空，不猜姓名、亲属、日期、精确地点。confidence≥80 的 AI 标签进入普通分类；低分和无标签进入待确认。阈值是整理策略，不是统计准确率，也不等于用户确认。

结果在 Vault 管理的 `.depdek-file-index` redb `content_annotations_v1` 中，绑定路径+SHA，字段向后兼容，重建 `files_v1` 不丢分类。人工确认保存在 confirmed_photo_labels；现有 photo_tags_v1 的人物/地点/事件优先于同维度 AI 标签。相同内容不同路径不共享身份或人工决定。读取目录只查当前索引快照，打开原图/保存前核验原件；源文件变更后应刷新，不能把快照当实时磁盘状态。

`photo_classification_query` 支持 libraryId 绑定、精确 dimension+label、status、offset/limit、groupOffset；组每页24、每组3张封面、items最多100。输出 counts={photos,annotated,unclassified,review}，groups={dimension,label,total,confirmed,ai_suggested,covers}，items={file,tags,labels,analyzed,needs_review}；labels 带 source=ai/user。人数等多标签和多维度计数不可相加当作照片总数。只供 Tauri 用户入口，不给 Agent 任意 fs 或新 RPC 工具，不用于 Webdesk 管理员接口。

自动处理一次最多12张，串行调用真实 Content Agent；缓存有效分类和人工分类修正被跳过，旧记录缺少结构化字段可补分析（保留人工标题、描述和标签）。每次请求只含当前缩略图，不携带历史、全库或 tasks/history.json。切换 Home、卸载或停止后不再启动新请求，正在执行的单次请求可能完成并保存；部分失败可查看并由用户重试。云端需明确选择目标模型并勾选本批发送授权；本地模式仍由 Rust 复验。

## 测试用例

| 场景 | 预期 |
| --- | --- |
| 海边人物 | 同时进入可见人物/旅行/海边，不臆造姓名或城市 |
| 生日蛋糕与多人 | 可有生日/多人合影；没有日期证据不编生日或年龄 |
| 无明确地标的山景 | 山野/风景，不自动命名为某座山 |
| 宠物、美食、收据、截图 | 分入内容类；有用与否不能据此删除 |
| 模糊或证据不足 | 低分候选只出现在待确认，不污染普通分类 |
| 多维度、同图多标签 | 同一分类去重计数，跨类允许重复；精确过滤不误命中同名其它维度 |
| 人工小满/三亚 | 优先使用用户确认，重新分析不覆盖 |
| 人工确认空集合 | AI 分类被撤回，重跑不复活它 |
| 重复文件不同路径 | 原件各自保留、标签和确认不串用 |
| 重扫/重新打开 | 同 SHA 分类仍可读；改版 SHA 不带旧分类 |
| 越界、符号链接、跨 Home、Agent session、修订冲突 | 拒绝并审计，不能把模型 JSON 当数据库命令 |
| 云端未同意/本地模式选择远端/仅浏览 | 不发模型请求 |
| 缓存、失败、停止、过期批次 | 不重复分析已完成项；只报真实回执；停止后不启动后续项 |
| 非法 JSON、未知词表、超长/重复标签、分数越界 | 双层校验拒绝，不写成功标记 |

自动测试以受控结果检查协议、调度、归组和 KV；不冒称验证视觉模型识别准确率。真实质量验收请用授权样本，在所选视觉模型上核对以上场景，记录误分/漏分及用户修正；不在开发测试中暗中上传家庭照片。

建议真实验收集：海边人物、生日、山景、宠物、美食、截图/票据各10张，另加20张低清/遮挡/无明显事件照片；包含同内容副本、人物同名和同一地点多次出行。先由用户标出可见内容和应当保持未知的信息，再逐张跑所选模型。按维度记录精确率（正确分类数/全部建议数）、召回率（找回的正确分类/应有分类）、待确认占比及人工改动数；不以自评 confidence 当准确率。姓名、亲属、日期或精确城市的无依据断言单独记为严重错误，不用更高召回抵消。真实结果尚未测得时不填分数。

本地自动测试：`npm run test:photo-classification`；sidecar：`npm --prefix sidecar test -- test/contentAgent.test.ts`；Vault：`cargo test --manifest-path src-tauri/Cargo.toml --no-default-features vault::file_index`。可操作示例：`DEPDEK_TREASURE_PREVIEW_PORT=1432 npm run preview:treasure`，打开 `http://127.0.0.1:1432/?workspace=album&scene=classify`；它只使用合成照片和内存结果，不代表原生 KV 或模型识别质量。
