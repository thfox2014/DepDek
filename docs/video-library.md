# 视频 · 本机闭环（2026-10-20）

原生 AI-OS 左栏在「相册」下方、「资料」上方增加「视频」。仍由悟空对话，右侧按三幕展示：**找回一段 / 留下精彩 / 串成故事**。沿用相册暖白、墨绿、纸面细线和可收起面板，不增加角色或独立设置页。

## 已实现范围与限制

- 添加视频复用 `file_library_import`：本机复制、自动分类与完整 SHA 索引；单文件 64 MiB，原件不移动。已有 Home 可显式建立索引，不自动扫描。
- 找回一段：按文件名、路径、SHA 前缀及已确认人物/地点/事件/日期/备注检索，分页。本机显式加载后播放；不自动批量加载视频、不访问外部链接、不上传模型。
- 留下精彩：人工标记/取消保留、修正标签，按完整 SHA 查看完全相同副本；不推断质量、相似片、人脸或家庭身份，不删除原件。
- 串成故事：用户添加原片、调整顺序、移除选片、命名，保存后可重新打开，逐段播放原片。**是故事选片草稿，不是合并/剪辑/配音/导出的视频。**不从文件修改时间推断拍摄日期。
- 播放仅对通过签名检查的 MP4/MOV、WebM/Matroska、AVI 提供有界本机字节；容器识别不等于浏览器支持其编码。超过 64 MiB、损坏或编码不支持明确说明；暂未提供大文件流式播放、自动转码或语音转写。
- 2026-10-21：原「标注这段」改为「AI 自动标注」，接入共享 [AI Content Agent](ai-content-agent.md)。点击后在本机读取原片，抽取最多 6 帧，按所选模型分析；结果单独存入 content_annotations_v1，带取样时间/模型/修订，可修正且可搜索。不把抽帧描述当成全片或音轨理解；人工标签仍独立保存。

## 数据与接口

公共文件 KV 的 `files_v1`、`category_v1(videos)`、`sha_v1` 仍为原始索引。私有 redb 增量两张表：

- `video_tags_v1`：path → `{path, sha256, tags, revision, updated_at_ms}`。标签沿用 PhotoTag 的字段/长度/日期校验，但独立存储；同 SHA 不同路径不共享标注，源 SHA 变化后旧标注不召回。
- `video_stories_v1`：UUID → `{id, title, references:[{path,sha256}], revision, updated_at_ms}`。引用顺序即播放顺序；不复制媒体，不保存模型推断或外发 URL。新建 expectedRevision=0，更新必须匹配当前 revision，过期拒绝。重复点击同一旧版本不会重复追加或覆盖。

四个命令见 `contract.md`。查询无库时返回真实空结果与当前 library_id，不创建 KV；故事列表不受当前搜索词过滤，草稿中的旧引用保留可追溯，源改变时预览/再保存拒绝。所有写入和媒体读取绑定查询回执 libraryId，切换 Home 后旧请求不能作用到新空间。标题 1–120 字、无控制符；引用路径规范、不能重复、SHA 为 64 位十六进制。标签每种最多一个，最多 16 条。

权限只通过 `Vault::file_index_audited`：已登录原生 user、固定 Home 锁、源目录 fd/nofollow、拒绝软硬链接、受保护路径及越界，提交前再查登录；操作成败均持久审计。原片读取额外记录来源审计；64 MiB 单片及 256 MiB 故事预算防无界内存/磁盘扫描。索引重建保留人工表。浏览器/sidecar/R1/Webdesk 不注册此能力，不改变它们的身份边界。

## 状态与验证

空库、无匹配、加载中、鉴权失败、源变更、版本冲突、文件过大和编码不支持分别呈现；失败不回退示例或伪造成片。选片只在当前 Home 面板内存保留，保存才写 KV；收起面板保留状态，离开视频或换 Home 释放播放器与对象 URL。聊天匹配仅建议场景/搜索，不自动保存标签、播放、写故事或外发。

验证覆盖查询分页/标签隔离/重扫、源变更及软硬链接/父目录替换、库切换/未登录/Agent 拒绝、大小/日期/故事重复引用与版本冲突，以及前端入口顺序、场景、意图误路由和草稿顺序。

验证命令：`npm run test:videos`、`cargo test --manifest-path src-tauri/Cargo.toml --no-default-features vault::file_index::videos`。`npm run preview:videos` 启动独立演示；只使用内存记录和 3 秒 AI 示例照片静帧，不读真实 Home。真实存储/导入/审计在重新构建启动的原生应用中使用；预览不会把内存回执称为持久化。
