# 悟空小剧场

2026-10-21；AI-OS 原生悟空聊天区的局部扩展，不修改 Vault、模型、Sidecar 或 Webdesk 接口。

## 体验

挥舞金箍棒、打瞌睡、喝茶、筋斗云、吃俺老孙一棒、烦死了六种短动画。延续现有扁平悟空；没有背景视频、声音或新动效依赖。欢迎页在原头像所在区域播放；有对话时在最新消息后单独展示，不覆盖消息、输入框或右侧操作面板。

每次 4–6 秒。首次等待 4–8 秒，之后休息 28–52 秒；洗牌袋保证一轮六种各一次且跨轮不连续相同。暂停期间不积累、不补播，恢复仍受冷却限制。动画只做 transform / opacity，没有常驻 RAF 或帧级 React 更新。

“悟空小剧场”明确表示这是装饰性片段，不是模型回答、任务状态、用户评价或已执行动作。台词不会写入聊天、记忆或发给模型。

## 不打扰

- 输入草稿、录音/转写、生成回复、保存配置、模型配置弹窗、待审批操作时暂停并移除当前贴纸。
- 页面隐藏、读历史或选择文字时不播放。不抢焦点，纯装饰内容不通过 live region 反复朗读。
- 仅在用户位于对话末尾时展示，保持该位置；读历史时不强制滚到末尾。
- 聊天头部星形开关可键盘操作，本机外观偏好键 `jiaho.agent-room.moments`，取值 `on/off`；不保存个人内容。
- 系统 `prefers-reduced-motion: reduce` 时不调度贴纸，动态切换立即停止；CSS 同时提供减少动效兜底。
- 卸载或改变上下文清理定时器与监听器；调度器始终最多一个未完成定时器。

## 实现与验证

- `src/lib/wukongMoments.ts`：六动作元信息、随机洗牌袋、有界调度。
- `src/components/WukongMoment.tsx`：复用头像、关节动作、可见性/滚动/选择/减少动效门禁。
- `src/components/wukong-moment.css`：六套有限动画及窄屏布局。
- `DepDekAiOsShell`：外观开关、输入/录音/生成/审批门禁，未改变消息内容与发送过程。
- `npm run test:wukong-moments`：动作覆盖、洗牌不重复、间隔、暂停/卸载清理、冷却、实际渲染和无外部请求依赖检查。
- `npm run preview:ai-os-room`：loopback 1426 的隔离预览；“六种悟空动效”打开图鉴并可重播，无模型与家庭资料连接。

本批更新 Linux 应用包及当前临时 VM 应用，不重启 Linux，也不重制或覆盖先前的 ISO。新旧应用包及运行验证另存 `os/artifacts/`；Live 会话仍不保证重启持久化。未登录时仍先显示原有账户/初始化门禁，不为了展示动画绕过认证。
