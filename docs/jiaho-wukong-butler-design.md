## 1. 学 Muse 的交互，不复制它的身份

用户指定 Meta 最近发布的 Muse。已核对 Meta 官网入口及其链接的 [How We Designed Muse](https://introducing.muse.ai/)，参考的是**个人 Agent 产品**，不是仅以 Muse Spark 模型名推断其界面。

官方设计文章强调连续主对话、后台任务、必要的结构化决定及可交互产物。以下是面向家合的设计取舍，而不是对 Muse 所有实现或表现的断言。

| 借鉴方向 | 家合的处理 |
|---|---|
| 持续对话 | 一个悟空、一段可以接着说的主对话；先不增加复杂会话管理 |
| 后台工作 | 用户可以再交代另一件事；正在办、待选择、已完成各有回执 |
| 主动帮助 | 只带来有用结果和必要决定；设备记录不直接当作用户习惯 |
| 明确的控制 | 接收方、敏感资料外发、不可逆动作使用结构化核对，不藏在聊天暗示里 |
| 丰富产物 | 找到的原件、资料包、照片挑选、灯光控制按需在右侧呈现 |
| 人格与形象 | 家合保留既有悟空，不开放多个拟人角色或复杂人格编辑器 |

主要区别：家合的家庭原件与授权知识以本机为主，不采用“所有东西放到云端个人电脑”的默认；Agent 也不因管家身份取得系统 root、磁盘或凭据权限。Muse 的安全文章同样区分执行环境与外部安全控制；家合必须继续沿现有 Vault / Gateway 实现。[Meta 安全设计](https://research.meta.ai/blog/security-and-safety-for-ai-agents-our-approach-with-muse)

官方参考页在内置浏览器加载超时，未取得逐像素参考截图。本稿是基于官方交互说明和家合现有代码的原创演进，不标为视觉复刻。

## 2. 管家意味着什么

不是“聊天更像人”，而是四件事：

1. **认得已允许记住的事**：偏好和档案有来源，能纠正、能忘记。
2. **接得住交代的事**：能明确说出范围、缺项和下一步，不把一句回答当作办完。
3. **持续照看未完成的事**：后台有持久任务；重启后知道该恢复、查证还是等用户。
4. **把重要的决定留给人**：日常安全处理不反复询问；真正会造成影响时，说明清楚后再做。

“像家”来自可靠、熟悉和分寸，不来自假装读懂孤独或制造依赖。悟空不猜测婚姻、亲子关系和情绪，不借摄像头分析谁忽视谁，不用“我一直等你”“只有我懂你”索取注意。

交流基调：短、具体、诚实，有温度。可以说“我在，慢慢说”；不能把没有执行的事说成“放心，都搞定了”。

## 3. 唯一日常主界面

```text
┌ 家合 ───────── 悟空 · 当前状态 ───── 镜头 / 处理方式 / 外观 ┐
│ 悟空          │                                          │
│ 交给我的事    │  持续的一段主对话                         │ 按需出现
│ 我的家        │  简短回答 + 正在办的任务 + 结果入口        │ 资料 / 核对
│ 家的记忆      │                                          │ 控制 / 产物
│ 我的资料      │                                          │
│               │  语音 / 文字输入                         │ 可关闭
│ 设置 · 空间   │  办事时仍然可以接着说                    │
└───────────────┴──────────────────────────────────────────┘
```

### 左边是找回入口，不是应用商城

悟空始终是当前主对话。任务、家、记忆、资料打开右侧工作区，不把聊天销毁或跳到另一页；关闭后继续刚才的草稿和对话。技术设置放左下角。原有照片、视频、文档应用能力仍保留，但作为被悟空打开的业务视图，而不是要求用户猜应用入口。

主界面不显示 Token 排行、模型品牌、执行器选择、十几个技能卡、四个 Agent 或 CPU 面板。需要诊断时可以找得到，不把诊断当日常入口。

### 中间是一个人可以接着说的地方

- 首次：一个悟空头像、一句“我在，慢慢说。家里的事，交给我。”、三个可做的小事。
- 熟悉后：继续主对话；只在有来源且获准时使用偏好，不伪造对家人的熟悉。
- 用户可以连续发消息；任务不锁住输入框。多个任务的进展分别归并到卡片。
- 不把每个工具调用刷成一条聊天，不展示内部思维链；只显示已执行阶段与可公开依据。
- 看旧消息时不强制滚到底部，新进展用轻提示找回。

### 右边是一张工作台，不是第二个聊天机器人

默认收起。任务需要选择、来源或可操作产物时展开，只聚焦一件事；关闭不会取消任务。返回、关闭、正在处理和不可用均有明确状态。

固定面板类型：`任务进展 / 原件与证据 / 资料包 / 设备控制 / 记忆 / 必要决定 / 私人登录`。正式版本由受控模板渲染，不执行模型随意生成的 HTML/JS。

手机右侧改为覆盖抽屉，能明确回到对话。家庭屏提供大字；深浅模式不改变权限。头像小幅动效可停用，系统“减少动态效果”优先。

## 4. 语音是主入口，文字是随时可用的退路

默认按键说话，唤醒词作为可选设置。未同意前不持续录音；关镜头不能自动开声纹。真实产品的语音状态机是：

`空闲 → 采音 → 转写草稿 → 用户确认/既定安全口令 → 交接任务 → 结果回执`。

普通聊天先把转写作为可修改草稿，用户发送；预先限定的家电安全口令可在明确模式中直接执行。转写中仍能取消并回到键盘，取消旧会话不能回填到新草稿。

打断的是说话或当前生成，不等于撤销已发出的外部动作。语音停止、模型停止、任务取消必须是不同动作。私人信息的语音播报默认克制，不能在公共家庭屏自动念出证件号。

本 HTML 只有“模拟聆听→示例草稿”，不申请麦克风权限、不接 ASR、不宣称低延迟指标。

## 5. 三条要先做实的流程

### A. 收好这些资料

用户交代 → 沿用已有导入范围 → 文件索引分类 → AI Content Agent 生成可追溯描述候选 → 建立分组视图 → 只报告结果和需要核对的少量问题。

缺省不搬动、不改名、不删除；照片/视频/文本共享内容分析产物，不能各自再跑一套相互冲突的识别。用户纠正保留为高优先级有来源事实，模型更新不能悄悄覆盖。

### B. 家里有事，帮我备好

“准备洗衣机维修资料” → 找对象及有权原件 → 检查日期和缺项 → 日期冲突一次核对 → 生成资料包清单 → 用户查看。

购买日期与登记日期可以同时存在。选择“暂不确定”不阻断能做的准备；本次清单选择不自动升格为长期事实。发送售后是另一次有接收方、附件和内容快照的动作。

### C. 环境刚刚好

“客厅灯调亮一点” → 确定设备与范围 → 执行安全控制 → 验证回读 → 简短结果 + 恢复入口。

常用灯光无需二次弹窗；无回读则是未知，不是成功，不自动重复发送。不把这个权限扩大到门锁、用电安全设备、摄像头、账号或支付。

## 6. 主动服务：高价值，低打扰

默认只主动报告四类：交代的事完成、确实阻塞需要决定、有依据且临近的重要节点、用户显式要求关注的变化。普通扫描与中间进度在任务列表更新，不响铃刷消息。

每个主动项有 `reason / source_refs / usefulness / expires_at / dedupe_key / visibility`。这里的 usefulness 是解释其用途的规则/判断，不拿一个分数自动删除资料。拒绝或忽略后抑制同来源重复建议；安静时段、频率上限、合并窗口由调度层执行，不能只靠模型自觉。

习惯先成为候选：“三晚有相似的灯光记录，要不要安排睡前柔光？”而不是“我知道你每天几点睡”。不凭设备行为推断身份、服药、健康结论或家庭关系。

## 7. 接到现有 DepDek 的方式

本节为候选组件和投影，不登记新的运行接口。落地前仍必须同步 `docs/contract.md` 并检查 Rust / sidecar / React 三方。

```text
DepDekAiOsShell（唯一日常 Shell）
 ├─ WukongConversation：主对话 / 草稿 / 语音 / 轻状态
 ├─ StewardTaskTray：后台工作与接手请求
 └─ ContextPanelHost：受控业务面板
       ↓ typed commands + event projections
现有 Session/Engine + Command Hub + Job/Action + Context
       ↓ Vault 校验范围、主体、证据、版本、审计
索引 / AI Content / 相片 / 视频 / 文档 / Memory / Secrets
```

| 现有实现 | 重构方式 | 不可越过的边界 |
|---|---|---|
| `DepDekAiOsShell.tsx` | 分离对话、任务托盘、面板宿主；现有路由互达保留 | 不在本轮自动替换生产入口 |
| `WukongHead.tsx` / 小剧场 | 头像呈现真实状态；表演不冒充进度 | 用户输入、核对、录音时不抢注意 |
| `useRoomVoice.ts` | ASR 草稿与输入方法复用；取消有会话代次 | 不让陈旧回调回填新草稿 |
| `TreasurePanel / VideoPanel / NativeDocumentsPanel` | 封装为现有业务的上下文视图，保留独立入口兼容 | 不用原型虚构数据顶替真实接口失败 |
| `AI Content Agent / file_index` | 后台阶段和结果引用投影进任务卡 | 原件 / 描述 / 确认分别存；KV 不变成权限源 |
| 共享长期记忆 | 继续 propose/confirm/reject/tombstone | 删除必须阻断索引与上下文召回 |
| Pi / Harness | 只作为可替换的执行实现，输出相同任务/产物投影 | Shell 不绕过 Gateway 暴露凭据或任意工具 |
| 登录弹层与 Provider 配置 | 复用现有本机登录失效恢复；设置收在非日常入口 | 管理员配置不等于获得私人内容权；不把 Key 发给模型 |

Webdesk 仍是独立远程管理服务，不直接读 Home 数据目录。需要远程呈现管家业务时，只能使用已认证的业务 BFF/网关；不能为减少页面层数，把 Webdesk 的 admin 直接当 Vault 业务用户。

## 8. 数据与 UI 投影候选

沿用现有本体、领域任务、Action 与 JSONL 记忆事实源，不再新建一套“悟空知道的一切”大 JSON。可以在业务 SQLite 中建立可重建投影；是否增加表和迁移需先核对当前 R1/V2 实际落地状态。

| 投影 | 最小字段 | 关键规则 |
|---|---|---|
| 主对话条目 | `id, conversation_id, owner_ref, role, content_ref, task_refs, created_at` | 主对话连续，不等于每次把全量历史发给模型 |
| 管家任务视图 | `task_ref, title, phase, public_summary, result_refs, decision_ref, revision` | 引用现有 Job/Action；状态不是第二份执行事实源 |
| 产物 | `id, kind, owner_ref, source_versions, visibility, payload_ref, revision` | 源权限变更会失效或收紧产物；包含最小必要材料 |
| 面板 | `kind, resource_ref, allowed_actions, revision, expires_at` | 服务端决定可操作项，前端不能自己赋权 |
| 需要用户决定 | `decision_ref, question, choices, effects, policy_revision, evidence_snapshot` | 绑定内容快照和有效期；聊天中的随意“好”不替代高影响确认 |
| 主动消息 | `task_ref, reason, source_refs, dedupe_key, expires_at, visibility` | 去重、频控、作用域过滤在可信层执行 |

概念事件：`task.progress / task.needs_input / task.result_ready / action.unknown / panel.invalidate`。事件通知只带引用和最小公开信息；客户端收到后按当前权限取投影，不直接广播家庭明文。

概念命令：`steward.task.start / inspect / cancel`、`steward.decision.resolve`、`steward.artifact.open`。这些是**尚未登记的方法名**，不能在原型中调用，也不能将其写成已有 API。

执行仍遵循：幂等键 + 证据/策略版本 + 检查点 + 受控提交 + 回执。事件至少一次交付、可重放、按聚合序号去重；不承诺跨设备/外部 API “恰好一次”。结果未知先查证，不支持幂等的外发禁止盲目重试。

“停止”只停止未执行步骤；本地派生视图可以撤销，外部发送只能按可用手段补偿。界面不能把所有行动都标为可回滚。

## 9. 上下文与记忆：熟悉来自准确，不来自窥探

每轮只组合：当前明确目标、相关任务状态、已授权的少量偏好、有权限的资料/证据片段。先做权限和删除过滤，再召回排序，再进入模型；家庭屏访客、家庭共享与个人空间不能共用无边界主对话。

显式“请记住”可按既定低风险偏好策略记录，避免再问一次；模型从行为推测的习惯仍是候选。身份、账户、证件完整值走加密引用，不能写进普通对话记忆；语音身份不能替代登录。

忘记要同步影响检索、向量派生物、缓存、上下文和同来源再生成；历史对话、原件删除与记忆停止使用是不同范围，用户能看清楚。加密状态必须来自可信存储回执，不能以一个锁图标代替。

## 10. 首月重构顺序与退出条件

| 批次 | 交付 | 退出条件 |
|---|---|---|
| 1 · Shell 收敛 | 单悟空、连续输入、可关右栏、三业务视图复用 | 相片/视频/文档可进入；输入草稿不丢；渲染错误局部捕获 |
| 2 · 一件事有始有终 | 资料收纳的持久任务 + 幂等 + 阶段/结果卡 | 进程重启不重复创建；停止不误称回滚；原件完整 |
| 3 · 资料变成帮助 | 维修资料包、缺项、冲突与一次必要核对 | 日期不覆盖；每项可溯原文；外发必须另核对 |
| 4 · 熟悉与回访 | 经过授权的偏好、记忆修正/忘记、低打扰回执 | 删后不可召回；不同成员不越权；云端范围可解释 |

感知硬件、Home Assistant/Matter、全屋主动自动化不塞进这四批；按上一份架构的独立硬件门槛推进。先让没有摄像头、没有本地 GPU 的家庭也能完成一件有用的事。

## 11. 必须验证，但尚未通过的验收场景

1. 十分钟内导入并找到一份真实资料，原件和校验可追溯。
2. 整理任务运行中继续聊天，消息和任务结果不串线。
3. 重启恢复同一任务，不重复副作用；等待核对仍等待。
4. 日期冲突保留两证据，“未知”不阻断其他准备。
5. 没有本机模型时准确显示不可用，不伪装绿灯或偷偷外发。
6. 云端使用范围与当前任务、策略版本绑定，不继承过宽授权。
7. 灯光回读丢失显示未知；核实过程不再次执行。
8. 取消语音后旧转写不覆盖新草稿；中文输入法回车不误发。
9. 登录失效保留对话/草稿；重新登录不重放写动作。
10. 不同家庭成员、私人/共享产物和匿名家庭屏无跨界泄露。
11. 记忆忘记后，全文、向量、缓存和模型上下文都不可召回。
12. 手机和家庭屏能关闭面板返回聊天，键盘/读屏/减少动效可用。

本轮仅完成交互原型、静态检查和设计交付预览。上述真实场景需接线后逐项验收，不能把原型的模拟结果计为产品通过。
