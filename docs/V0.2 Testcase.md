# DepDek V0.2 Testcase

> 对应需求：[V0.2 PRD](<V0.2 PRD.md>)
>
> 测试对象：Inbox、邮箱账户配置、IMAP 兼容 bridge、本地邮件状态和本地 AI 整理
>
> 通过标准：P0 全部通过；P1 无阻断性问题；安全与契约回归不得失败。

## 1. 测试环境与命令

| 类别 | 环境/命令 |
|---|---|
| 前端类型与生产构建 | `npm run build` |
| sidecar | `npm --prefix sidecar run build`、`npm --prefix sidecar test` |
| Rust Core | `cd src-tauri && cargo test --no-default-features` |
| 浏览器回归 | `npm run dev -- --host 127.0.0.1`，使用浏览器预览 fixture |
| 桌面产物 | `npm run tauri build`，再执行 `codesign --verify --deep --strict` 和 `hdiutil verify` |

浏览器预览不得访问外部邮箱；真实 IMAP 用例使用隔离测试账户或注入的 fake IMAP client，不使用个人生产邮箱。

## 2. 用例约定

- P0：发布阻断，必须通过；P1：本 Sprint 允许已知限制，但不得影响核心闭环；
- “本地”指当前 Vault root；“远端”指 IMAP 服务或任何第三方写操作；
- 所有用例都记录截图/日志/审计证据，敏感凭据必须脱敏。

## 5. P0 安全与契约回归

| 编号 | 场景 | 预期 |
|---|---|---|
| TC-V02-022 | 读取/写入 `../outside`、绝对路径、symlink 越界 | Rust Vault 拒绝并返回对应 E32001/契约错误；审计记录失败 |
| TC-V02-023 | 超过单文件上限、非 UTF-8 文件 | 返回 E32003/E32005；应用不崩溃 |
| TC-V02-024 | sidecar 运行并输出协议 | stdout 只有 NDJSON 协议行；日志进入 stderr；无直接 fs/bash 工具 |
| TC-V02-025 | `mail/accounts.json` 不存在或非法 | 返回 -32002 或可解释配置错误；不吞掉异常 |
| TC-V02-026 | 不同账户同 UID | 本地路径和索引按账户隔离，不互相覆盖 |

## 7. 自动化/手工映射

- sidecar：邮件无配置、UID 幂等、单账户失败、Markdown 渲染、正文修复、UIDPLUS 远端删除、危险账户名由现有 Vitest 覆盖；
- Rust：Vault 越界、symlink、大小、审计由现有 cargo tests 覆盖；
- 前端：`npm run build` 覆盖类型和生产构建，TC-V02-001～021 通过浏览器回归执行；
- 前端任务中心：TC-V02-034～035、TC-V02-039～040、TC-V02-045～047 验证 `running → progress/log → success/error` 生命周期、批处理日志、日历同步和 Today 顶部入口范围；
- 日历 sidecar：ICS 解析、聚合去重、CalDAV 写回和只读 provider 防护由 `calendar.test.ts` 覆盖；
- 打包：TC-V02-030 使用 Tauri bundle 产物和系统校验命令执行。
