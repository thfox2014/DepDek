## 发现与修复历史

1. [P1] 内嵌浏览器日期控件显示已填写，但生日未提交到选片状态。补充 `onInput`、`onBlur` 与原有 `onChange`；重新实际填入 2008-02-12，选片结果显示 0、4、18 岁，缺失 16 个年龄段。拍摄日期字段同步采用该兼容处理。
2. [P2] 查询失败与空库共用空状态，误引导用户重新建库。改为独立“暂时没能打开宝箱 / 重新打开宝箱”，再次打开 `?error=1` 核对。失败状态不写成未有照片或已完成扫描。
3. [P2] 主按钮悬停继承旧工作台浅色背景，白色文字对比度不足。增加宝箱主操作专用悬停样式；修复后实测 `hovered=true`、背景 `rgb(35,70,60)`、文字 `rgb(255,253,248)`，功能可用，截图再次比较。
4. 数据状态复查发现零匹配结果可能被跨场景已选照片遮住；空态判断改为按当前场景/编辑器处理，保留故事选片但不把它冒充当前查询结果。
5. 收起照片面板原先会卸载选片状态；改为隐藏现有面板，实际收起/展开验证仍保留标题、生日、年龄和选片。

最终比较无遗留可执行的 P0/P1/P2 界面问题。照片异步解码期间展示加载状态属于预期；最终比较使用实际图像载入完成的截图。

## 实际交互验收

- 回忆、挑选、成长影片可在同一会话内切换；输入成长影片请求后，建议改变，场景等待用户选择。
- 右侧主要操作栏在各场景均为 3 个动作；标签编辑为 2 个。内容选择、输入和分页作为直接操作保留。
- 标签编辑、修改、保存，以及聊天明确标注填入待核对表单的逻辑已实现。浏览器验证手工编辑保存；解析逻辑另由单测覆盖。
- “查看相同副本”结果为 2 个实例；“标记保留”出现真实服务回执驱动的已保留状态，未调用删除。
- 选片默认不重复选择相同内容；用户可修改。生日、年龄、缺失年龄、故事播放/暂停、草稿保存均已点击验证。
- 面板收起/恢复保留当前工作；390×844 下照片抽屉可收起继续聊天。根元素无横向溢出，照片操作栏下沿为 844px、未越出视口。
- 空库和服务错误分别有真实状态；前端过期请求保护、读取错误和不支持图片格式有对应处理。
- 检查浏览器 `error` 与 `warn` 日志：均为 0。
