# 家合 · 家庭中枢 v0

2026-10-22，可交互概念稿。品牌、单悟空与暖白墨绿延续现有家合；感知与设备功能都是明确标记的模拟，不是已经实现的运行能力。

## 打开

直接打开 `index.html`，保留同目录的 CSS、JS 和 assets。没有 CDN、字体下载、构建依赖或后端请求。也可以：

```sh
python3 -m http.server 1442 --bind 127.0.0.1 --directory docs/design/jiaho-home-hub-v0
```

然后访问 `http://127.0.0.1:1442/`。

## 可体验

- 悟空：点击找眼镜、调灯、习惯起点，或输入文字；语音按钮只填入固定示例草稿，不请求麦克风。
- 我的家：选房间，调整客厅亮度，查看回执并恢复上次亮度。
- 家的记忆：查看偏好来源、忘记并撤销；查看三晚灯光依据，修改/启用/忽略/暂停一个习惯。
- 我的资料：分类与名称搜索、添加示例、AI 标注候选和描述修正；不读取任何真实文件。
- 安心与设置：查看镜头硬件回报、语音/身份识别边界及一般问题云端偏好。
- 右侧：按任务变化；小屏为可关闭抽屉。顶部切深浅主题；桌面可收起整个面板。
- 左下私人空间：模拟锁定和登录恢复，不填写真实账号密码。
- 演示设置 / Tweaks：标准三栏、大字陪伴、安静夜间三种显示变体；模拟遮罩、断网、无本地模型、回读丢失、空资料库。回读丢失后取消模拟故障，再核实结果，不会重新下发指令。

## 诚实边界

所有数字、房间、文件、观察和回复均为虚构示例。刷新即清空；没有 localStorage、摄像头、录音、真实推理、设备调用、上传、持久化、实际登录或真实隐私证明。视音频、健康监护、硬件供电与模型时延需要未来真机验证。
