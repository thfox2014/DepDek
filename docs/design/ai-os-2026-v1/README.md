# AI-OS 2026 · 轻透极简

2026-10-24，第二版独立 HTML 设计稿。按用户新反馈，参考 2026 年官方设计更新，收起空操作面板、删除重复说明，采用图标 Dock、轻透表面、短入口与内容优先的对话。旧拟物稿保留在相邻目录。

双击 **AI-OS-2026-轻透.html** 可离线打开，图片、图标、CSS、脚本均内嵌，无 CDN 依赖。

```sh
node docs/design/ai-os-2026-v1/prepare.mjs
python3 -m http.server 1439 --bind 127.0.0.1 --directory docs/design/ai-os-2026-v1
```

本机：[打开预览](http://127.0.0.1:1439/)。右上调色板打开外观，可切换浅色/深色和轻透/纯净/专注；大字也在这里。三角按钮体验示例，开始对话后变成新对话。短入口填草稿；发送显示内置演示，点击产物打开可勾选清单。相册、视频、资料保留独立草稿与上下文。

所有交互仅页面内存，不调用模型、读取家庭文件、使用麦克风或配置账户。右上「预览」说明完整范围和设计来源。手机底部 Dock 保留四个目的地，设置/工作台/锁定移入外观面板，仍可到达。APP_VERSION 从根目录 VERSION 导出，正式 Shell 未改。

规格与素材：`brand-spec.md`。官方来源与采用理由：`research.md`。源文件：`index.html`、`prototype.css`、`prototype.js`；`prepare.mjs` 重建离线交付件。
