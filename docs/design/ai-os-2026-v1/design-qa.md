# 第二版 HTML 检查记录

2026-10-24。

- 先检索并读取 Apple 2026 设计资源/WWDC26、Google 官方 Material 更新入口与 Microsoft Design 2026-06-29 文章。来源、日期、采用与舍弃记录在 research.md；不声称存在单一「2026 标准风格」。
- 在 1280×720 浏览器查看浅色首屏：图标 Dock、一个问候、输入和三条短入口；默认没有右栏和长说明。最终单文件也已独立打开并保存截图。
- 实际操作浅/深色切换；实际操作示例对话、产物打开清单、勾选一项并看到计数由 0/3 到 1/3。查看展开后的对话与右栏，输入始终可达。
- 实际切换相册，点击「海边」填入草稿，再点击发送，确认草稿清空、发送按钮禁用、出现相册上下文示例回复与产物。
- 修正外观图标与设置面板的重复 ID，检查全部静态 ID 唯一、SVG 引用完整。JS 语法检查通过；单文件不加载外部图片、脚本或样式。官方参考链接仅在用户主动点击后打开。
- 页面不包含网络请求、localStorage、麦克风调用或真实模型接线。用户输入用 textContent 渲染；Enter 有 IME 保护。手机响应式/安全区、图标 accessible name、焦点标签与减少动态/透明效果已做源码检查；本轮未做设备矩阵验收。
- 未改正式 Shell 或三方接口，因此没有运行无关的 Rust/sidecar/原生构建。
