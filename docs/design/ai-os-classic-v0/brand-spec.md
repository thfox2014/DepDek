# AI-OS「经典拟物」HTML 稿

日期：2026-10-24。用户要求在现有浅色、深色以外探索第三种 iPhone 4 时期的拟物风格，先交付 HTML。

模式：Redesign · Preserve，独立外观原型。保留左侧伙伴/相册/视频/资料导航、中央悟空对话、右侧操作面板和家合品牌身份。原生 Shell、路由、接口、权限与主题存储均不改动。

现有实现：`src/components/DepDekAiOsShell.tsx` 与 `src/components/ai-os-room.css`。已有浅色主题为暖灰白 `#faf9f6` / `#f1f0ec`，深色为 `#1c1c1b` / `#232322`；外观切换位于聊天标题栏。原型内的浅/深色是相同结构的对照稿，不是正式 Shell 的嵌入。

真实素材：`assets/jiaho-brand/logo.png` 复制自 `src/assets/jiaho-boot-logo.png`；`assets/jiaho-brand/wukong.svg` 沿用已有悟空头像。图标前景从已安装的 Phosphor Icons 提取，授权见 `assets/PHOSPHOR-LICENSE.txt`；拟物容器、高光、材质和纸页为本稿 CSS / SVG 矢量实现，不使用 Apple 图标或商标。

Design Read：家庭资料管家的近距离桌面界面；暖棕皮革、细亚麻布、奶油纸、玻璃高光与金属按钮。视觉变化 5、动效 3、密度 4、素材依赖 4、品牌一致性 8。稳定三栏与较低密度保护中文阅读；材质集中在导航、标题与便笺，正文保持清楚。动作 120–200ms，以按压与展开反馈为主，服从减少动态效果。

定位：日常对话页，不是品牌宣传页；桌面 50–80cm 阅读。温暖、熟悉、有触感。首屏只包含欢迎语、三条起点、输入与一张便笺，不增加统计墙。

颜色：纸白 `#f8f4e8`、正文 `#413b31`、次要文字 `#817665`、皮革 `#6b4530` / `#9a7050`、选中蓝 `#376eac` / `#6da3d5`、亚麻 `#cecdc5`、便笺 `#fff3bc`、金属 `#c8cbd0` / `#f1f2f3`。图标按原应用语义使用蓝、青、黄与石墨派生色。

字体：沿用系统中文 PingFang SC / Noto Sans CJK SC；拉丁与数字 Helvetica Neue；标题 32–38px，正文 14–16px，辅助信息 12px。4px 间距基数；侧栏 212px，右栏 292px，正文最大 660px；图标 48px、圆角 10px。阴影分为图标投影、纸页层次和弹窗浮层；正文不应用发光效果。触摸目标至少 44px。

可交互：三种主题切换、四个目的地、示例对话、草稿与发送示例回复、操作面板展开/关闭、风格说明、材质细节与大字 Tweaks。只用内存，不连接真实资料/模型/麦克风/账户；所有内容明确标注示例。
