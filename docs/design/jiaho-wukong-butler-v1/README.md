# 悟空家庭管家 · 交互原型 v1

配套设计：[悟空作为家合 Shell](../../jiaho-wukong-butler-design.md)。上一版家庭中枢保留在 `../jiaho-home-hub-v0/`。

## 打开

推荐在仓库根运行：

```sh
python3 -m http.server 1443 --bind 127.0.0.1 --directory docs/design/jiaho-wukong-butler-v1
```

浏览器打开 `http://127.0.0.1:1443/`。SVG 图标精灵使用同目录资源，建议经本机 HTTP 预览，不依赖 file:// 的跨资源策略。

## 可以体验

1. 点击「整理这些资料」，处理期间继续输入「把客厅灯调亮一点」；两件事分别保留任务/回执，输入框不锁死。
2. 输入「帮我准备洗衣机维修资料」，右侧核对购买/登记日期；可以选择「还不确定」，继续准备清单。下载仅产生明确标注的示例文本，不含原件。
3. 点击语音，待填入示例草稿再发送；没有请求麦克风权限，也没有真实 ASR。
4. 说「请记住，回答简单一点」，打开「家的记忆」查看来源并忘记；删除后不再使用该偏好，除非你重新明确要求记住。
5. 「演示设置」选择日常管家 / 陪伴大字 / 专注办事；深浅主题独立切换。可模拟空库、本机模型不可用和设备回读丢失。

所有数据只留页面内存，刷新即重置。没有真实模型、设备、登录、上传、文件识别或加密实现。没有改动原生界面，也没有更改 Rust / sidecar / React 协议。

## 文件

- `index.html`：页面结构。
- `prototype.css`：既有家合设计系统的响应式实现。
- `prototype.js`：孤立示例状态和交互。
- `assets/`：随包分发的真实项目资产及 Phosphor 图标。
- `prepare-assets.mjs`：仓库内可重复导出素材的机械脚本；预览不需要运行它，也不需要安装依赖。
- `brand-spec.md`：品牌、来源与参考边界。

交付检查：JS 语法、本地资源路径、图标符号和静态危险调用检查；查看实际首屏及关键结果用于设计交付截图。未执行正式应用或跨设备验收，未宣称已完成产品闭环。
